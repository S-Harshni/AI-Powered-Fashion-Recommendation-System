Overview

Shoppers often find an item they like and want more like it. This system learns what clothes look like (fabric, cut, pattern) and uses that to recommend visually similar products.

I trained a ResNet classifier in TensorFlow on the DeepFashion dataset, then reused its learned feature layer as an embedding for a nearest-neighbor recommender with sub-second retrieval.

Highlights

  • ResNet classifier trained on DeepFashion (289K+ images, 50 categories)
  • Modular pipeline: preprocessing, augmentation, hyperparameters, train/test
  • Feature layer captures fine-grained fabric, style and pattern
  • Nearest-neighbor recommender: sub-100ms inference, sub-second retrieval

How it works

  1. 01

    Preprocess DeepFashion

    Crop garments with the dataset's bounding boxes, split train/val/test and build category + attribute labels.

  2. 02

    Train ResNet

    Train a ResNet classifier in TensorFlow with training-time augmentation and configurable hyperparameters.

  3. 03

    Extract embeddings

    Use the network's feature layer as a compact descriptor of fabric, style and pattern.

  4. 04

    Recommend by similarity

    Nearest-neighbor search over the embeddings returns the most visually similar items.
